# KARSU 🚀

> AI-powered learning and productivity platform built with privacy, security, and intelligent assistance in mind.

## ✨ About

**KARSU** is an AI-powered platform designed to help users **learn, create, solve problems, and improve productivity** with intelligent assistance.

The project combines AI with a privacy-first approach, secure authentication, safety guardrails, and a modern mobile experience.

## 🔥 Features

- 🤖 AI-powered assistance
- 📚 Learning & productivity tools
- 🔐 Secure authentication
- 🧠 Privacy-aware AI personalization
- 🛡️ AI safety guardrails
- 👤 User onboarding & profiles
- 🗄️ PostgreSQL database
- 🔄 Automatic database migrations
- 🐳 Docker support
- 📱 Flutter mobile application

## 🛠️ Tech Stack

**Frontend:** Flutter / Dart  
**Backend:** Node.js / TypeScript / Express  
**Database:** PostgreSQL  
**AI:** OpenAI API  
**Infrastructure:** Docker / Docker Compose

## 🔒 Privacy & Security

KARSU follows a **privacy-first architecture**.

- AI personalization is **opt-in by default**
- Secure password hashing
- Expiring authentication sessions
- Session revocation on logout
- Environment-based secrets
- No hard-coded database passwords
- Minimal AI context sharing

> Never commit API keys, passwords, `.env` files, or other secrets to the repository.
